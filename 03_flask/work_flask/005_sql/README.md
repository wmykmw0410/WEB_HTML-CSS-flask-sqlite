## SQL・データベースの基礎

### データベースとは

データを構造化して保存・検索・更新できる仕組みです。表形式でデータを管理する **リレーショナルデータベース（RDB）** が広く使われています。

```
books テーブル（= 1 枚の表）

| id | title          | author   | price |
|----|----------------|----------|-------|
|  1 | Python入門     | 山田太郎 |  2800 |
|  2 | Flask入門      | 鈴木花子 |  3200 |
|  3 | SQLite実践     | 佐藤次郎 |  1980 |
```

| 用語 | 説明 | Excel での例 |
|---|---|---|
| **データベース** | データの入れ物（`.db` ファイル） | ブック（ファイル） |
| **テーブル** | 同じ種類のデータの集まり | シート |
| **カラム（列）** | データの項目定義（id / title / price など） | 列ヘッダー |
| **レコード（行）** | 1件分のデータ | 1行 |
| **フィールド** | 1レコード内の1項目の値（行と列の交点） | 1つのセル |
| **スキーマ** | テーブルの設計図（カラム名・型・制約の定義） | 1行目のヘッダー全体 |

### SQL とは

**SQL（Structured Query Language）** はデータベースを操作するための言語です。

| 分類 | 命令 | 用途 |
|---|---|---|
| **DDL**（定義） | `CREATE TABLE` / `DROP TABLE` | テーブルの作成・削除 |
| **DML**（操作） | `SELECT` / `INSERT` / `UPDATE` / `DELETE` | データの取得・追加・更新・削除 |

### SQLite とは

SQLite は**ファイル1つ**でデータを管理できる軽量なデータベースです。サーバ不要で手軽に使えるため、学習・プロトタイプ・小規模アプリに広く使われています。

```
通常の DB：アプリ ──▶ DB サーバ ──▶ データファイル
SQLite  ：アプリ ──▶ .db ファイル（直接読み書き）
```

### 用語集

| 用語 | 説明 |
|---|---|
| **RDB**（リレーショナルデータベース） | 表形式でデータを管理し、表どうしを関連付けて扱えるデータベース。MySQL・PostgreSQL・SQLite などが代表例 |
| **SQL**（Structured Query Language） | データベースを操作するための言語。読み方は「エスキューエル」または「シーケル」 |
| **クエリ** | データベースへ送る SQL の命令文。「問い合わせ」とも呼ぶ |
| **主キー**（PRIMARY KEY） | レコードを一意に識別するカラム。同じ値が2つ存在できない。`id` カラムに設定するのが一般的 |
| **`AUTOINCREMENT`** | レコードを追加するたびに自動で 1 ずつ増える番号を振る仕組み |
| **NULL** | 値が存在しない（未入力）ことを表す特別な値。`0` や空文字とは異なる |
| **NOT NULL** | NULL を許可しない制約。必ず値が入っていなければならないカラムに指定する |
| **CRUD** | データ操作の4種類の総称。Create（追加）/ Read（取得）/ Update（更新）/ Delete（削除）の頭文字 |
| **DDL**（Data Definition Language） | テーブルの構造を定義する命令。`CREATE TABLE` / `DROP TABLE` など |
| **DML**（Data Manipulation Language） | テーブルのデータを操作する命令。`SELECT` / `INSERT` / `UPDATE` / `DELETE` など |
