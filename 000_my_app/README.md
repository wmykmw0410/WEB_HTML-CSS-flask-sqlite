# 000 自分だけの学習統合アプリ

`001`以降の各チャプターはテーマごとに独立したサンプルですが、`000_my_app`は**自分で学んだ内容を1つのアプリに積み上げていく**ための場所です。各章を終えるたびに、その章で学んだ機能をこの`app.py`（や、必要に応じて分割したファイル）に反映していきます。

## 1つのアプリを育てる

`001`〜`025`を通して、1つの**メモ帳アプリ**を少しずつ育てていきます。

| 対象チャプター | 積み上がる機能 |
|---|---|
| `001`〜`018` | 一覧・詳細・追加・ログイン・所有権付きCRUD |
| `019`〜`020` | JavaScriptによる機能追加（文字数カウント・絞り込み・ピン留め）・自動テスト |
| `021`〜`023` | 外部API連携（郵便番号から住所解決）・JSON APIのフルCRUD化 |
| `024`〜`025` | ロールベースの認可（管理者/一般）・非同期処理 |

`018_ownership_crud`で所有権とCRUDが完成し、`019_javascript`でJavaScriptによる機能追加、`020_testing`でこのメモ帳アプリの自動テストを行います。`021_webapi`で外部API（zipcloud）との連携、`022_flask_api`・`023_crud_api`でメモ帳アプリ自身のJSON APIをフルCRUD化し、`024_role_management`でロールベースの認可（管理者/一般）を追加します。テーマの切り替えは一切なく、`100_memo_api`が最終的な完成形です。
