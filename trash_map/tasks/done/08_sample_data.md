# サンプルデータの登録・表示調整

日付: 2026-08-29

## これは何をする作業か

アプリの見た目を確認しやすくするため、実際に1件サンプルデータをDBに登録し、あわせて一覧ページの見た目をテーブルからカード形式に変更する。

## 手順

1. 「燃えるゴミ」のサンプルレコードをDBに1件登録する。名前は「東京駅前ゴミ箱」、郵便番号は〒100-0005、緯度経度は地図で使っている東京駅マーカーと同じ座標にする。
2. `trash_map/static/trashcan.jpg`（元々用意されていたサンプル画像）を `trash_map/static/uploads/trashcan.jpg` にコピーし、このサンプルレコードの `photo_filename` に設定する。
3. 見た人が「これはサンプルデータだ」とすぐ分かるように、名前を `【サンプル】東京駅前ゴミ箱` に変更する。
4. `trash_map/templates/trash/type_list.html` の見た目を、テーブル表示からカードグリッド表示に変更する。
   - 各カードの上部に、写真を4:3の比率でカバー表示（`object-fit: cover`）し、写真がメインの見た目になるようにする。
   - 名前・住所・座標は写真の下に補足情報として表示する。
   - 写真が登録されていないデータは、「写真なし」というプレースホルダーを表示する。
5. カード内の住所表示の順番を、「〒郵便番号（改行）住所」の順にする。日本の一般的な住所の書き方（郵便番号が先）に合わせた。

## 動作確認

- `/list/burnable` にアクセスし、サンプルデータが写真付きのカードとして表示されることを確認する。
