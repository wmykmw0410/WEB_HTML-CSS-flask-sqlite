# 周辺検索機能を追加

日付: 2026-08-29

## これは何をする作業か

「現在地から探す」ボタンを押すと、ブラウザの位置情報を使って現在地周辺（選んだ半径以内）のゴミ箱だけを地図に表示し、近い順の一覧も出せるようにする。

## 設計方針

新しいAPIは作らず、既に取得済みの `/api/trashcans` の全件データを使い、ブラウザ側（JavaScript）で距離計算する方式にした。登録件数が少ない今の規模ではこれで十分シンプルに実装できる。件数が数百〜数千件に増えたら、サーバー側で絞り込む方式への切り替えを検討する（`tasks/todo.md` に記載）。

## 手順

1. `trash_map/templates/map/map.html` に、検索用のUI部品を追加する。
   - 「現在地から探す」ボタン
   - 検索半径を選ぶセレクトボックス（500m/1km/3km）
   - 「クリア」ボタン
   - 検索結果件数などを表示するステータス欄
   - 近くのゴミ箱を一覧表示するパネル（`#nearbyList`）
2. `trash_map/static/js/map.js` に、以下の関数を実装する。
   - `distanceMeters(lat1, lng1, lat2, lng2)` — 2地点間の距離をメートル単位で計算する（Haversine公式という、地球が丸いことを考慮した計算式を使う）。
   - `runNearbySearch(userLat, userLng)` — 「現在地から探す」ボタンが押されたときに呼ばれる。現在地とすべてのゴミ箱の距離を計算し、選んだ半径以内のものだけを地図に表示、それ以外は非表示にする。あわせて近い順にソートした一覧を作る。
   - `clearNearbySearch()` — 「クリア」ボタンが押されたときに呼ばれる。全てのマーカーを再表示し、検索結果をリセットする。
3. 「現在地から探す」ボタンのクリックイベントで、ブラウザの位置情報APIを呼び出す。
   ```javascript
   navigator.geolocation.getCurrentPosition(
       position => runNearbySearch(position.coords.latitude, position.coords.longitude),
       () => { statusEl.textContent = '現在地を取得できませんでした。'; }
   );
   ```
   ブラウザが位置情報に対応していない場合や、ユーザーが許可しなかった場合はエラーメッセージを表示するようにする。
4. 現在地には、他のゴミ箱ピンと区別できるよう専用の丸いマーカー（青色）を表示する。
5. 検索結果に合わせて `map.fitBounds(...)` を呼び出し、該当するゴミ箱と現在地が画面内に収まるように地図をズームする。
6. `trash_map/static/trash.css` に、上記UI部品（`.map-controls`, `.nearby-list` など）のスタイルを追加する。
7. 検索コントロールが地図標準のズームボタン（画面左上）と重なってしまう問題が見つかったため、`.map-controls` の位置を `left: 50%; transform: translateX(-50%);` として、上部中央に移動する。

## 動作確認

1. `/map` にアクセスし、検索UI一式（ボタン・セレクト・ステータス欄・一覧パネル）が表示されることを確認する。
2. `static/js/map.js` に構文エラーがないことを `node --check` で確認する。
3. 実際にブラウザで「現在地から探す」を押し、位置情報の使用許可ダイアログが出ること、許可すると周辺のゴミ箱だけが表示されることを確認する（この環境では自動テストできないため、手動でのブラウザ確認が必要）。
