# 緯度・経度のバリデーションメッセージ日本語化とプレースホルダー追加

日付: 2026-08-30

## これは何をする作業か

緯度・経度の入力チェック自体はすでにできていたが、エラーメッセージが英語のままだった。日本語のメッセージにし、あわせて入力例（プレースホルダー）を表示して何桁くらい入力すればいいかが分かるようにする。

## 手順

1. `trash_map/form.py` の `latitude` / `longitude` フィールドを開く。もともと `input_required()`（未入力チェック）と `NumberRange`（範囲チェック）のバリデーションは付いていたが、メッセージ引数を指定していなかったため、`Number must be between -90 and 90.` のような英語のデフォルトメッセージが表示されていた。それぞれに `message=` 引数で日本語のメッセージを指定する。
   ```python
   latitude = FloatField("緯度: ", [
       validators.input_required(message="緯度を入力してください"),
       validators.NumberRange(-90, 90, message="緯度は-90から90の範囲で入力してください")
   ], render_kw={"placeholder": "(例)35.681236"})
   ```
   経度も同様に、`-180`〜`180` の範囲で同じパターンのメッセージを設定する。
2. 同じフィールド定義に `render_kw={"placeholder": "..."}` を追加し、入力欄に薄いグレーの文字で入力例を表示する。緯度・経度どちらも、地図で使っている東京駅の座標（`35.681236`, `139.767125`）を例にした。

## 動作確認

1. 緯度・経度に範囲外の値（例: `999`）を入力して送信し、「緯度は-90から90の範囲で入力してください」のような日本語のエラーメッセージが表示されることを確認する。
2. 緯度・経度を空欄のまま送信し、「緯度を入力してください」「経度を入力してください」が表示されることを確認する。
3. `/add` の緯度・経度の入力欄に、プレースホルダーとして `(例)35.681236` / `(例)139.767125` が薄く表示されていることを確認する。
