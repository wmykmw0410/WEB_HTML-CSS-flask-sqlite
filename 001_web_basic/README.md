# 001 Webサイトの仕組み

Flaskのコードを書き始める前に、Webサイトが動く仕組みを座学として押さえておくチャプターです。ブラウザからのリクエストがどう処理されて画面に表示されるのか、HTTP・サーバの役割・アプリケーションの設計パターン・ネットワークの基礎を理解しておくと、この後のFlask学習の全体像がつかみやすくなります。

## 学習内容

- [web_basic.md](web_basic.md) — Webサイトが表示されるまでの流れ、フロントエンド/バックエンドの違い、HTTP/HTTPS、HTTPメソッド、HTTPステータスコード、Cookieとセッション、MVTモデル、静的/動的サイト、URLの構造、プロトコル一覧、ドメイン、ネットワーク基礎（IPアドレス・ポート）、ブラウザの開発者ツール、curlコマンド
- [web_advanced.md](web_advanced.md) — さらに踏み込んだネットワークの知識（OSI参照モデル、TCP/UDPの違い、ルーター・スイッチ・ハブ、NAT、DHCP、ファイアウォール、リバースプロキシ、ロードバランサー、VPN）。任意で読む発展編

## 進め方

1. まず[web_basic.md](web_basic.md)を通しで読む
2. 余裕があれば[web_advanced.md](web_advanced.md)にも目を通す
3. 次の[002_html_css](../002_html_css/)からは実際に手を動かしてコードを書いていく
