em と rem の違い

親：font-size 20px

子：1.5em → 親の20px × 1.5 = 30px

子：1.5rem → ルート（html）の16px × 1.5 = 24px

ブラウザの設定で文字サイズを大きくしたユーザーにも対応できるよう、文字サイズには rem を使うのが一般的です。

行の高さ（line-height）

line-height: 1.7。日本語の本文は1.5〜1.8くらいが読みやすいとされます。行と行の間に適度な余白があると、長い文章でも目が疲れにくくなります。

line-height: 1.1。行間が詰まっていると、長い文章では次の行を見失いやすく、読みにくくなります。見出しなど短い文には向いています。
