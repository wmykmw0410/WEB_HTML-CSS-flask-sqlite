カスケード・詳細度・継承

開発者ツール（F12 / Cmd+Option+I）の「Elements」で要素を選び、「Styles」パネルを見てください。負けたスタイルには取り消し線が付いています。

1. 記述順

同じセレクタが2回 → 後に書いた方（青）が勝つ

2. 詳細度

p だけ (0,0,1) → 灰

.specificity p.text (0,2,1) が .specificity .text (0,2,0) に勝つ → 緑

#special (1,0,0) がすべてに勝つ → 紫

style属性はどのセレクタよりも強い → 茶

3. 継承

親の color と font-size を引き継ぐ（でも p で color: gray を指定しているので灰色になる → 直接指定は継承より強い）

span には p のルールが無いので親の青色を継承する

border: inherit で親の枠線をあえて引き継ぐ

4. !important

ID セレクタ（teal）より !important（crimson）が勝つ
