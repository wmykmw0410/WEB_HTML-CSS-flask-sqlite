何色になる？（解答）

Q1：クラスなしの p

Q2：class="q"

Q3：class="q hot"

Q4：class="q hot" id="q4"

Q5：class="q level"

Q6：.note の中の p（親の gray は継承される？）

問題正解理由
Q1red .quiz p (0,1,1) が、body div p (0,0,3) と p (0,0,1) に勝つ（左の桁から比べるので、要素がいくつあってもクラス1個の差は覆らない）
Q2brown .quiz .q (0,2,0) が .quiz p (0,1,1) に勝つ。 さらに .quiz .q は2回出てくるので、後に書かれた brown が勝つ
Q3purple .page .quiz .hot は (0,3,0) で、クラスの数が最も多い
Q4blue ID を含む #q4 (1,0,0) は、クラスがいくつあっても勝てない
Q5brown .level (0,1,0) は後に書かれていても、詳細度が高い .quiz .q (0,2,0) に負ける（記述順で比べるのは、詳細度が同じときだけ）
Q6red 継承（親の gray）よりも、その要素に直接当たるルール .quiz p が常に優先される
