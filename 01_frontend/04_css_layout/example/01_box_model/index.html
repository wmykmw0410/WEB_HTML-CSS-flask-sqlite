ボックスモデルとdisplay

1. content-box と border-box

content-box（デフォルト）
見た目の幅は 200 + 20×2 + 4×2 = 248px
border-box
見た目の幅がちょうど 200px

実務では、最初に次のリセットを書いてすべての要素を border-box にするのが定番です。

*, *::before, *::after {
    box-sizing: border-box;
}

2. 省略記法（padding / margin 共通）

padding: 16px;
padding: 8px 24px;
padding: 4px 24px 16px;
padding: 4px 8px 16px 32px;

3. margin: 0 auto で中央寄せ

幅を決めたブロック要素は margin: 0 auto で中央に寄る

4. マージンの相殺

margin-bottom: 30px
margin-top: 20px → 間隔は 50px ではなく 30px

5. display

span を block に → 横幅いっぱい・改行される
div を inline に
→ 横に並ぶ（width/height は効かない）

inline-block 横に並びつつ 幅・高さも効く display: none は表示されない（場所も取らない）

6. overflow

overflow: visible（デフォルト）。高さを超えた中身は枠の外にはみ出して表示されてしまいます。はみ出しています。

overflow: hidden。高さを超えた中身は切り取られて見えなくなります。切り取られています。
overflow: auto。高さを超えたときだけスクロールバーが出ます。スクロールできます。スクロールできます。
