Flexbox と Grid の使い分け

  • Flexbox：1列に並べる（ナビ・ボタンの並び・カードの中身）
  • Grid：行と列で格子状に並べる（カード一覧・ページ全体の骨組み）
  • 両方を組み合わせるのが普通（ページの骨組みはGrid、ヘッダーの中はFlexboxなど）
