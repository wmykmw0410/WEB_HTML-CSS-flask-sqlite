テキストと基本タグ

見出しと段落

段落はp要素で囲みます。見た目を大きくしたいだけで見出しタグを使ってはいけません（大きさはCSSで変える）。

強調

strong は「重要」、em は「強調（読み上げで抑揚が付く）」という意味を持ちます。 見た目だけ太字・斜体にしたい場合は CSS を使います。

説明リスト（dl）

HTML
ページの構造（何が見出しで、何が段落か）を表す言語
CSS
ページの見た目（色・大きさ・配置）を指定する言語
